What is LLM serving?

Running a model so that many people can send requests and get replies at the same time. A serving engine sits between the users and the GPU.

Users

Many requests arrive at once

Serving engine

Queues, batches and schedules the work

GPU

Holds the model weights and the KV cache

Replies

Streamed back token by token

GPUs are expensive. Every hour of idle compute costs money.

GPU memory is limited. Weights take most of it; requests share the rest.

Wasted memory means fewer users served per GPU, at a higher cost each.
