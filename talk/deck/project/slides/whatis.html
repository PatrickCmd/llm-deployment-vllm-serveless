The engine

What is vLLM?

An open-source, high-throughput serving engine for LLMs. It does not change the model's answers. It stops wasting GPU memory and time, so one GPU serves more users.

Idea 1

PagedAttention

Manages the KV cache in small blocks, like an operating system pages memory.

Idea 2

Continuous batching

Swaps finished requests for waiting ones at every decode step, so no GPU slot idles.
