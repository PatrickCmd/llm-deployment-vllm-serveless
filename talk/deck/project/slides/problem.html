The problem

The KV cache eats GPU memory

A naive engine reserves one contiguous block per request, sized for the longest possible answer. Most answers are short, so most of the reservation sits empty.

Request A

50 of 2,000 slots used

Request B

600 of 2,000 slots used

Request C

180 of 2,000 slots used

Request D

no room left, must wait

Over-reservation

Memory reserved but never used, and unavailable to anyone else.

Fragmentation

Free memory split into gaps too small and scattered to fit a new request.

The real bottleneck

Memory management, not math speed, limits how many users a GPU serves.
