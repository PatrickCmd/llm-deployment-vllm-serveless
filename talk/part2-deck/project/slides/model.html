A vLLM-ready model is a Hugging Face folder

vLLM does not want a binary or a converted format. It loads the transformers checkpoint directory as it is. Sunbird/Sunflower-Gemma4-E2B on the Hub:

FileSizeRole
config.json1 KBGemma4ForConditionalGeneration, bf16
model.safetensors10.2 GBWeights: 5.1 B params, ~2 B effective
chat_template.jinja3 KBApplied by /chat/completions
tokenizer.json + config33 MBTokenizer
processor_config.json1 KBImage and audio preprocessing
generation_config.json1 KBDefault sampling (temp 1.0, top-k 64)

If you fine-tuned it yourself

  • Merge LoRA adapters into the base weights
  • save_pretrained in safetensors, not .bin
  • Keep tokenizer and chat template in the same repo
  • Set torch_dtype in config.json
  • hf upload org/name ./merged
