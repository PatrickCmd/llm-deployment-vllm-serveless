Step 6 · The client

Same code as Part 1, task 5. Two lines changed.

from openai import OpenAI

 

client = OpenAI(

    api_key=os.environ["RUNPOD_API_KEY"],

    base_url=f"https://api.runpod.ai/v2/{EP}/openai/v1",

)

r = client.chat.completions.create(

    model="sunflower-gemma-2b",

    messages=[

      {"role": "system", "content": "You are Sunflower…"},

      {"role": "user", "content":

        "Translate from English to Luganda: Where is the nearest hospital?"},

    ],

    max_tokens=128, temperature=0.0,

)

# → Eddwaliro erisinga okumpi liri ludda wa?

Routes you get

  • /openai/v1/models, chat/completions, completions
  • /run + /status: async queue, survives any cold start
  • /runsync: sync queue, ~90 s
  • /health: worker and queue counts

Model-specific habits

  • Fixed template: Translate from X to Y: …
  • temperature 0, per the model card
  • Streaming: stream=True, nothing else
  • Vision and audio: content lists with base64
