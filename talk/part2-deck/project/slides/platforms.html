Decide on four things: where your data and identity already live, how much you want to write (Python, YAML or clicks), the GPU price you can live with, and whether you need a queue in front of cold starts. RunPod and Vast have one; Modal, Cloud Run and Hugging Face make the client retry. Lambda has no GPUs; Bedrock import does not yet support Gemma 4.
