One command, scale to zero built in

runpodctl serverless create \

  --template-id 1py0k4aw3b --name sunflower-gemma-2b \

  --gpu-id "NVIDIA GeForce RTX 4090" \

  --workers-min 0 --workers-max 2 \

  --idle-timeout 120 \

  --scale-by delay --scale-threshold 300 \

  --min-cuda-version 13.0 \

  --model-reference \

    https://huggingface.co/Sunbird/Sunflower-Gemma4-E2B:44e5d28f…

 

→ ENDPOINT_ID oy9jxtbeq3c4ks · gpus ADA_24 · workers 0–2

  scalerType QUEUE_DELAY · flashboot true · minCuda 13.0

workers-min 0

Scale to zero. min 1 keeps one warm at ≈ $800/month.

model-reference

RunPod's host model cache: weights sit on local disk, download time unbilled, pinned to one commit.

idle-timeout 120

Two minutes warm after a request, so a demo burst pays one cold start. Default is 5 s.

min-cuda-version 13.0

The vLLM 0.30 image is CUDA 13. Without the floor, old-driver hosts crash-loop.

no data-centre pin, no volume

A pinned volume starved GPU supply in July. The cache gives caching without the pin.
